# Data provenance

Scientific colormap lookup tables are generated by
`scripts/generate_colormaps.py` from exactly pinned development dependencies.
Consumers install the generated Mojo tables and never need Python or matplotlib.
Generation is accepted only when it is byte-reproducible and the per-map and
whole-file checksums below remain unchanged or receive an explicit provenance
review.

Every generated artifact must record:

- upstream project and canonical URL;
- exact upstream version or immutable revision;
- exact file checksums and licenses;
- generator source and command;
- deterministic output checks;
- review notes for semantic or licensing changes.

Generation tools are development dependencies. Consumers install the generated
Mojo data and do not require Python, Rust, C, or another runtime.
